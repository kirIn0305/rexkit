## 更新方法

- 研究上の問い、仮説、根拠、解釈は RQ 文書に記録する。
- ツールまたは機能の目的、要件、制約、設計判断は SPEC 文書に記録する。
- 関連する Experiment は `experiments/<この文書名>/EXP-xxx_name/` に置く。実行条件と記録は `TASK.md` に、測定値と解釈は `README.md` に記録する。
- Experiment の結果が RQ または SPEC の判断に影響したら、該当する文書を更新する。
- 過去の判断を削除せず、変更理由と根拠を履歴として残す。
